# 开发与版本管理

## 目录约定

- `aed-server/`：Spring Boot 后端，Java 17。
- `aed-web/`：Vue 前端，保留 `package-lock.json` 以便复现依赖。
- `sql/`：建表和演示数据脚本，不代表当前数据库备份。
- `docs/`：项目设计与开发说明。
- `tests/`：接口业务联调脚本。

## 首次配置

按根目录 README 准备数据库，将后端的 `application-local.example.yml` 复制为 `application-local.yml`，填写本地密码和随机 JWT 密钥。该文件从后端运行目录加载，须在 `aed-server` 目录启动。环境变量也可用于部署。上传图片、数据库和本地配置请单独备份。

## 构建检查

前端在 `aed-web` 中执行：

```bash
npm ci
npm run build
```

后端在 `aed-server` 中执行：

```bash
mvn package
```

编译通过不代表完整业务验收通过。`tests/api-smoke.sh` 需要已启动的后端和配套演示数据，会写入业务记录，并包含固定日期及 ID；运行前请检查并调整，仅用于独立测试数据库。

## 后续保存到 GitHub

在仓库根目录执行：

```bash
git status
git diff
git add .
git diff --cached --stat
git commit -m "描述本次修改"
git push
```

提交前确认没有密码、密钥、实际人员数据或数据库备份。`.gitignore` 已排除依赖、编译输出、本地配置、日志和上传图片。不要使用强制推送覆盖远程历史。
