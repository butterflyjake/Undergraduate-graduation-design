# 高校AED器械管理系统 — 前端设计

> 本文档是前端页面实现的唯一契约，也是毕业设计论文"系统实现"章节的素材。

## 1. 技术栈与目录结构

- Vue 3（组合式 API `<script setup>`）+ Vite + Vue Router + Pinia + Axios + Element Plus + ECharts
- 目录: `aed-web/src/` 下 `api/`(接口封装)、`views/`(页面)、`layout/`(布局)、`stores/`(状态)、`utils/request.js`(Axios 封装)、`config/menu.js`(菜单)

已就位的基础设施（页面开发直接使用）:
- `utils/request.js`: 自动携带 token, 统一处理业务码, 401 自动跳登录。**接口调用返回的是 `{code, message, data}`, 页面取 `res.data`**
- `stores/user.js`: `userStore.roleCode`(admin/device_manager/inspector)、`userStore.realName`
- 图片访问: 上传接口返回 `/upload/xxx.jpg`, 页面直接用该路径作为 img src(开发环境 vite 已代理)
- Element Plus 图标已全局注册, 直接用 `<el-icon><Xxx /></el-icon>`

## 3. 通用交互模式（所有列表页遵循）

1. **搜索区**: 页面顶部 `el-card` 内一行 `el-form`(inline), 放筛选条件 + "查询"/"重置"按钮
2. **表格区**: `el-table` + `el-table-column`, 分页用 `el-pagination`(current-page/page-size/total 绑定, layout="total, sizes, prev, pager, next")
3. **弹窗表单**: 新增/编辑用 `el-dialog` + `el-form`(rules 校验), 保存后刷新列表
4. **删除**: `ElMessageBox.confirm` 二次确认
5. **状态标签**: 用 `el-tag` 展示状态枚举(如设备状态: 在用=success, 维修中=warning, 停用=info, 报废=danger)
6. **枚举字典**: 各页面定义本地常量对象, 如 `const PART_TYPES = { 1: '电极片', 2: '电池' }`
7. **图片**: 表格中展示缩略图(`el-image` + preview), 表单中上传组件: 用 `el-upload` + `/api/file/upload`(headers 带 Authorization), 成功后将返回的 url 写入表单字段
8. **权限按钮**: admin/device_manager 专属操作按钮用 `v-if="['admin','device_manager'].includes(userStore.roleCode)"` 控制
9. **分页参数**: pageNum 从 1 开始, pageSize 默认 10

## 4. 数据看板约定（Dashboard.vue）

- 顶部 4~6 个统计卡片(el-card + el-statistic 或自定义), 数据来自 `/api/dashboard/overview`
- 图表区用 ECharts(echarts 按需 import `import * as echarts from 'echarts'`, ref 容器 + onMounted 初始化 + onBeforeUnmount dispose, 窗口 resize 监听)
- 图表清单: 设备状态分布(环形饼图)、近7天巡检趋势(折线图)、近6月维修/使用趋势(柱状图)、设备楼宇分布(柱状图)、临期配件清单(表格)
- 主题色建议: 主色 #409eff, 系列色 ['#409eff', '#67c23a', '#e6a23c', '#f56c6c', '#909399']

## 5. 巡检任务页约定（InspectionTask.vue）

- 巡检人员(inspector)看到"我的任务", 表格操作列有"执行巡检"按钮(仅 status=0 的任务)
- 执行巡检弹窗: 显示 6 个固定检查项(主机外观完好无破损/电源指示灯显示正常/电极片在有效期内/电池电量充足/机柜箱体完好/设备周边无障碍物), 每项单选"正常/异常"(el-radio-group), 异常时显示备注输入框, 另有"总体说明"文本域
- 提交调用 POST /api/inspection/record/submit
- admin/device_manager 看到"生成巡检任务"按钮(选日期, 默认今天), 调用 POST /api/inspection/task/generate

## 6. 风格要求

- 中文界面, 代码中文注释
- 页面根元素加 class, scoped style 保持简洁(间距 16px, 卡片圆角默认)
- 所有交互有 loading 状态与成功/失败提示(ElMessage)
- 表格无数据时显示"暂无数据"
